# e2e-shards assigns every package under ./test/e2e/... and every top-level
# test in every package to exactly one CI shard. The table is read by
# scripts/e2e-shards, which also checks it against the packages and tests the
# go tool reports.
#
# Format, one shard per line:
#
#   shard <name> <package> [<package>...] -- [<test>...]
#
# Packages before "--" are the packages the shard runs. Tests after "--" are
# the top-level tests the shard runs from those packages. A package listed by
# one shard runs all its tests, so it needs no test list. A package listed by
# several shards is split by test name: each of those shards runs only the
# tests its line names, and the coverage check fails unless every test of the
# package is named by exactly one of them, so a test cannot silently drop out
# of the gate.
#
# top-b is the catch-all shard for top-level tests: a new test of the top-level
# test/e2e package goes there unless it belongs with the tests in another
# shard.
#
# The split follows the slowest-test report of CI run 45021559562 on main and a
# local run of test/e2e/system on 2026-11-22 with -parallel 8. In that CI run
# the shard jobs took top-a 277 s, top-b 212 s and system 307 s. Inside system
# the top-level test/e2e package took 134.16 s and test/e2e/system took
# 254.00 s, in parallel, so the system package was the critical path.
#
# test/e2e/system is now split between system and system-b by test name, with
# the measured cost divided evenly: 50 tests totalling 412.02 s stay in system
# and 49 tests totalling 412.09 s move to system-b. system also keeps the two
# top-level tests TestCardRenewedDaily (98.75 s) and TestLocalRegistration
# (35.09 s), which run beside its system tests; that top-level package took
# 134.16 s. system-b runs only system tests. Both shards should land near half
# the old 254 s system package, well under the critical path. top-b already
# runs its copy of the top-level package at 164.40 s, so the split adds a shard
# rather than loading about 127 s of container tests onto top-b. The 32 s
# coverage check that run 45021559562 ran inside top-a now runs in the lint
# job, which takes top-a to about 245 s.
#
